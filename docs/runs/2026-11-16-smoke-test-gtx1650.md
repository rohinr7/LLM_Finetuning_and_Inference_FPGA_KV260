## Notes

- The 1650 is about three times slower than the T4 on the same job, as expected for a card with no tensor cores.
- Peak memory is about 1 GB on both cards, so memory is not the limit for a 0.5B model. A 1.5B model should still fit in 4 GB, to be measured.
- **Loss values differ between the two runs** on the same data and settings. The most likely cause is the library versions: the Kaggle run used an older transformers, while this run uses 5.20.2. Check this before trusting any loss comparison across machines. Pinning the versions in `requirements.txt` is the next step.
- The `use_reentrant` checkpoint warning and the `torch_dtype` deprecation warning both appeared again. Neither is fatal.
- As before, five examples over 20 steps only prove the pipeline works.
